# 樂朗奇 年度績效評核系統

同仁用手機開啟專屬連結填寫，資料存進執行長自己的 Google 試算表，執行長另有儀表板檢視結果。

## 檔案

| 檔案 | 用途 |
|---|---|
| `Code.gs` | 後端程式，貼到 Google Apps Script |
| `index.html` | 同仁填寫頁面與執行長儀表板，貼到 Google Apps Script |
| `dev/` | 本機測試工具，不需要部署 |

## 第一次部署（約 15 分鐘）

1. 用執行長的 Google 帳號建立一份新的 Google 試算表，例如命名為「績效評核」。**不要把這份試算表分享給任何人**，心聲問卷與所有評分都存在這裡。
2. 在試算表選單點「擴充功能 → Apps Script」。
3. 把編輯器裡預設的 `Code.gs` 內容全部換成本資料夾的 `Code.gs`。
4. 點左側「檔案」旁的「＋ → HTML」，檔名輸入 `index`，內容全部換成本資料夾的 `index.html`。
5. 在編輯器上方的函式下拉選單選 `setup`，按「執行」。第一次會要求授權，請同意。完成後試算表會多出「設定、名冊、部門指標」等工作表。
6. 點右上角「部署 → 新增部署作業」，類型選「網頁應用程式」，「執行身分」選「我」，「誰可以存取」選「所有人」，按「部署」，複製網址（結尾是 `/exec`）。
7. 回到試算表，把網址貼到「設定」工作表的「網頁網址」那一列的「設定值」欄。

之後如果更新了程式，要到「部署 → 管理部署作業 → 編輯 → 版本選『新版本』→ 部署」，網址不會變。

## 每年的操作流程

1. **設定**：在「設定」工作表確認「年度」「截止日」，並填入「月數_S／A／B／C」。
2. **名冊**：在「名冊」工作表填入所有同仁（先刪除三列範例）。
   - `直屬主管`、`同儕評核人` 可以填編號或姓名；同儕評核人用逗號分隔，建議每人 3 位。
   - 執行長自己也要列一筆，`角色` 欄填「執行長」。部門主管的 `直屬主管` 填執行長。
   - `參加評等` 留白會自動判斷：到職未滿 3 個月者不參加，只填心聲問卷與感謝卡。填「是」或「否」可以強制指定。
3. **產生連結**：重新整理試算表後，點選單「績效評核 → ② 產生專屬連結」。把每個人的「專屬連結」用 LINE 個別傳給本人。連結等同身分，請提醒同仁不要轉傳。
4. **填寫期間**：執行長用自己的專屬連結開啟，點「開啟執行長儀表板」，在「填寫進度」看誰還沒完成。
5. **校準**：全部填完後，在儀表板「評核結果」調整最終等第，「留任關懷」看需要面談的同仁。
6. **結案**：把「設定」的「開放填寫」改成「否」。點選單「績效評核 → ③ 匯出評核結果」，結果會寫入「結果」工作表。若要讓同仁看到收到的感謝卡，把「公開感謝卡」改成「是」。

隔年把「年度」改成新年度、更新名冊即可，舊年度的資料會保留在原工作表。

## 計分規則

- 每題 1–5 分，換算成 100 分制（平均 × 20）。
- 構面權重：工作成果 50、專業能力與成長 20、團隊合作 20、態度與品牌價值 10。
- 來源權重：主管 60、同儕 25、自評 15。同儕評分者不足 3 人或未填自評時，該部分權重併回主管評。
- 等第：總分 ≥ 90 且在人數上限內為 S，≥ 80 且在上限內為 A，< 60 為 C，其餘為 B。S 上限 10%、A 上限 30%。
- 以上數字都可以在「設定」工作表調整。
